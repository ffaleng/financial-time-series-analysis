# Financial Time-Series Analysis

A Python project for analyzing financial time-series data using pandas, NumPy, and Matplotlib.

## Features

- Load and clean OHLCV price data
- Convert dates to a time-series index
- Calculate daily returns and cumulative returns
- Calculate daily and annualized volatility
- Calculate drawdown and maximum drawdown
- Calculate rolling mean and rolling volatility
- Generate and save price visualizations
- Export processed data and summary metrics

## Key Metrics

- Total Return
- Annualized Volatility
- Maximum Drawdown

## Project Structure

- `data/` - input price data
- `outputs/` - processed data and summary results
- `figures/` - generated charts
- `main.py` - main analysis script

## Technologies

- Python
- pandas
- NumPy
- Matplotlib
